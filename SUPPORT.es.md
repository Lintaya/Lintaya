# Soporte de Lintaya

[English](SUPPORT.md) | Español

Lintaya es un proyecto open source en pre-release que se mantiene con el mejor
esfuerzo. Actualmente no hay un tiempo de respuesta garantizado ni un SLA de
soporte de producción.

## Dónde preguntar

- **Preguntas de uso y diseño:** GitHub Discussions, cuando esté habilitado.
- **Errores confirmados:** usa el formulario de issue para reportar errores.
- **Propuestas de funcionalidades, conectores o analizadores:** usa el formulario
  de issue correspondiente.
- **Vulnerabilidades de seguridad:** sigue [SECURITY.es.md](SECURITY.es.md) y
  repórtalas de forma privada.

Antes de pedir ayuda, revisa README.es.md, SETUP.es.md, ARCHITECTURE.es.md y el
roadmap open source.

## Información de diagnóstico útil

Incluye sistema operativo, versión soportada de Node.js, commit o versión de
Lintaya, módulo afectado, resultado esperado, resultado real y pasos mínimos de
reproducción. Los logs deben limitarse a las líneas pertinentes.

Elimina tokens, nombres de usuario, hostnames internos, URLs de repositorios,
direcciones IP, contenidos de bases de datos e información personal antes de
publicar. Si tienes duda, omite el valor y describe su tipo.

## Lo que el proyecto no puede proporcionar

- recuperación de cuentas o credenciales de terceros;
- acceso de depuración a infraestructura privada;
- ayuda para evadir controles de seguridad de proveedores;
- garantías de que ejecutar un repositorio no confiable sea seguro;
- soporte para runtimes EOL sin una política explícita de compatibilidad.
