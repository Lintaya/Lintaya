# Lintaya support

English | [Español](SUPPORT.es.md)

Lintaya is a pre-release open-source project maintained on a best-effort basis.
There is currently no guaranteed response time or production support SLA.

## Where to ask

- **Usage and design questions:** GitHub Discussions, once enabled.
- **Confirmed bugs:** use the bug report issue form.
- **Feature, connector or analyzer proposals:** use the corresponding issue form.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md) and report them
  privately.

Before requesting support, check `README.md`, `SETUP.md`, `ARCHITECTURE.md` and
the open-source roadmap.

## Useful diagnostic information

Include the operating system, supported Node.js version, Lintaya commit or
version, affected module, expected result, actual result and minimal reproduction
steps. Logs should be reduced to the relevant lines.

Remove tokens, usernames, internal hostnames, repository URLs, IP addresses,
database contents and personal information before posting. When in doubt, omit
the value and describe its type instead.

## What the project cannot provide

- recovery of third-party accounts or credentials;
- debugging access to private infrastructure;
- help bypassing provider security controls;
- guarantees that running an untrusted repository is safe;
- support for EOL runtimes without an explicit compatibility policy.
