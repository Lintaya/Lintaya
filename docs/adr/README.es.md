# Registros de decisiones de arquitectura

[English](README.md) | Español

Esta carpeta contiene los registros de decisiones de arquitectura (ADR) de Lintaya. Cada ADR documenta una decisión importante de diseño, su contexto y sus consecuencias para el trabajo futuro.

Comienza con los documentos numerados y usa el [índice de documentación](../INDEX.es.md) para volver a la documentación general del proyecto.
