# Terminology / Terminología

This table is the shared English–Spanish terminology source for Lintaya. Keep
code identifiers, protocol names, API paths, and product names exactly as
written in code.

| English | Español | Notes |
| --- | --- | --- |
| Connector | Conector | Provider integration or configured card, depending on context. |
| ConnectorType | Tipo de conector | The manifest-defined integration. |
| Connection | Conexión | A configured instance of a ConnectorType. |
| Block | Bloque | A dashboard content unit. |
| Board | Tablero (Board) | CLI name for a Module Builder page; retain `Board` in commands. |
| Module | Módulo | Full connector-owned view or product module. |
| Binding | Enlace | Typed relationship between a page and a block. |
| Action Registry | Registro de acciones | Canonical action contract for REST, CLI, and MCP. |
| Secret Store | Almacén de secretos | Storage boundary for connector secrets. |
| Connector SDK | SDK de conectores | Keep SDK as an acronym. |
| sync | sincronización | Keep `sync` in command or API identifiers. |
| Home | Inicio | Product route name is `Home`; Spanish UI may use Inicio. |
| workspace | espacio de trabajo | Keep `workspace` when it is a product-specific identifier. |
| pre-release | versión preliminar | Do not call the product stable until a release says so. |
