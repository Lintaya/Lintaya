# Dashboards

English | [Español](introduccion.es.md)

A Dashboard groups several Boards as upper tabs. It is a navigation container:
it does not copy Board layouts or Blocks.

From **Dashboards**, you can create or edit a Dashboard, choose its Boards,
change tab order, and control whether it is active and shown in the sidebar. An
empty Dashboard is valid too.

## Create the full hierarchy with the Assistant

The Assistant can create a new Dashboard together with its content Blocks and
Boards in one proposal. Describe the title, Board order, and the content that
belongs in each Board. Lintaya shows one confirmation card with the total number
of Boards and Blocks; nothing is saved until a person approves it through the
Approval Center.

The compound operation uses the real IDs generated by Lintaya and links the
hierarchy automatically. If a Dashboard, Board, or Block already has one of the
requested titles, the operation fails before it creates partial content. To
reuse existing content, the Assistant can also retrieve IDs through
`list_custom_blocks` and use the individual creation flow.

Each compound Board can choose a zone preset (`single`, `columns`, `rows`,
`grid`, `priority`, or `focus`). Blocks are placed into separate zones following
that preset. These Boards are hidden from the sidebar by default, making the
Dashboard their entry point. Content may include images with alternative text
and attribution; image URLs must use HTTPS.

The selected tab is persisted on the Dashboard. Tabs support mouse activation
and Left Arrow, Right Arrow, Home, and End. On narrow screens, the tab row
scrolls horizontally.

Drag a tab over another tab to change its position. The new order is persisted
on the Dashboard and also controls presentation order. With a keyboard, use
Alt + Left Arrow or Alt + Right Arrow to move the tab.

Inside a Dashboard, the pencil next to **Manage** opens the selected Board's
editor. The Board title is not repeated in the content because the active tab
already identifies the open Board.
Cancelling or saving from that editor returns to the same Dashboard.

The **Present** button (the Play icon next to Manage) opens a full-screen
Dashboard presentation. Use Left Arrow and Right Arrow or the visible controls
to move between Boards; Escape exits the presentation.
The eye button in the presentation header hides or restores every Block title
and its controls. The preference remains in effect while moving through Boards
and resets when a new presentation is opened.

If a referenced Board is inactive or missing, its reference is retained and
shown as unavailable. That allows it to be restored or relinked by a future
import. Deleting a Dashboard never deletes its Boards or Blocks.
