# Lintaya — propuesta visual v2

## Revisión del material existente
- `assets/brand/`: logos y símbolos canónicos claros/oscuros. Se conserva la identidad del faro.
- `assets/social/`: 20 piezas de campaña, 2 fondos y una vista general.
- El kit anterior enfatiza «Git Project Intelligence», ramas Git y «Manage. Run. Analyze. Improve.».

## Nueva dirección
Espacio de trabajo visual para herramientas e IA. Blocks → Boards → Dashboards.
Git se presenta como una integración, no como la definición completa del producto.
Se mantienen azul noche, cian y blanco, y el faro como símbolo de orientación.

## Alcance
Estas imágenes son propuestas principales de campaña, no sustituyen los recursos actuales ni son exportaciones finales para cada red social. Las composiciones de interfaces son ilustraciones conceptuales, no capturas reales.
La creación y operación de bloques/boards mediante IA es una visión del proyecto y no debe anunciarse como función disponible sin verificar su implementación.
